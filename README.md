# 숭실고 통일네컷 설치 안내

학생은 로그인 없이 링크로 들어와 네 컷을 찍고 질문을 제출합니다.
제출물은 선생님 구글 시트(질문)와 구글 드라이브(네컷 이미지)에 쌓이고,
선생님은 같은 페이지의 **선생님 모아보기**(주소 끝 `#teacher`)에서 비밀번호로 모아 봅니다.

| 파일 | 하는 일 |
|---|---|
| `index.html` | 학생용 촬영 페이지 + 선생님 모아보기. GitHub Pages에 올립니다. |
| `Code.gs` | 제출을 받아 시트와 드라이브에 저장하는 앱스 스크립트. 구글 시트에 붙입니다. |

---

## 1단계. 구글 시트와 앱스 스크립트 (약 10분)

1. 구글 드라이브에서 새 **구글 스프레드시트**를 만들고 이름을 `통일네컷 제출`로 정합니다.
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 편집기에 있던 코드를 모두 지우고 `Code.gs` 내용을 통째로 붙여 넣습니다.
4. 맨 위 `TEACHER_PASSWORD = '여기를-바꿔-주세요'`의 따옴표 안을 선생님만 아는 비밀번호로 바꾸고 저장(💾)합니다.
5. 위쪽 함수 선택 칸에서 **setup**을 고르고 **▶ 실행**을 누릅니다.
   - "권한 검토" → 계정 선택 → "고급" → "(안전하지 않음)으로 이동" → **허용**.
   - 직접 만든 스크립트라서 나오는 일반적인 경고입니다.
   - 실행이 끝나면 시트에 `제출` 탭이, 드라이브에 `통일네컷 제출 이미지` 폴더가 생깁니다.
6. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
   - 톱니바퀴에서 유형 **웹 앱** 선택
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - **배포**를 누르고, 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

> **"모든 사용자"가 목록에 없다면?** 학교 구글 워크스페이스 관리자가 외부 공개를 막아 둔 경우입니다.
> 이때는 개인 Gmail 계정으로 1단계를 다시 하거나, 학교 정보부에 허용을 요청하세요.
> "숭실고 내 모든 사용자"로 배포하면 학생도 학교 계정 로그인이 필요해집니다.

## 2단계. index.html에 주소 넣기

`index.html`을 메모장(또는 VS Code)으로 열고, 앞부분의 다음 줄을 찾습니다.

```js
const API_URL = "";
```

따옴표 안에 1단계에서 복사한 웹 앱 URL을 붙여 넣고 저장합니다.

```js
const API_URL = "https://script.google.com/macros/s/AKfy.../exec";
```

## 3단계. GitHub Pages에 올리기 (약 5분)

1. [github.com](https://github.com)에 로그인하고 오른쪽 위 **+ → New repository**를 누릅니다.
2. Repository name에 예를 들어 `tongil4cut`을 쓰고 **Public**을 선택한 뒤 **Create repository**를 누릅니다.
3. 새 저장소 화면의 **uploading an existing file** 링크를 눌러 `index.html`을 끌어다 놓고 **Commit changes**를 누릅니다.
   - `Code.gs`는 올리지 않습니다. 비밀번호가 들어 있기 때문입니다.
4. 저장소의 **Settings → Pages**에서 Branch를 **main / (root)**로 정하고 **Save**를 누릅니다.
5. 1~2분 뒤 같은 화면 위쪽에 주소가 나옵니다: `https://<내아이디>.github.io/tongil4cut/`

- 학생용 링크: `https://<내아이디>.github.io/tongil4cut/`
- 선생님용 링크: `https://<내아이디>.github.io/tongil4cut/#teacher`

## 4단계. 수업 전 점검

1. 휴대폰으로 학생용 링크를 열어 시험 제출을 한 번 합니다.
2. 선생님용 링크에서 비밀번호를 넣고 제출물이 보이는지 확인합니다.
3. 시험 제출은 모아보기의 **삭제** 버튼으로 지웁니다. 시트 행과 드라이브 이미지가 함께 지워집니다.

## 알아 두면 좋은 점

- **다시 제출하면 새 행으로 쌓입니다.** 학생이 고쳐서 다시 내면 두 건이 보이니, 필요 없는 쪽을 삭제하세요.
- **모아보기는 30초마다 자동으로 새로 불러옵니다.** 바로 보려면 **새로고침** 버튼을 누르세요.
- **원본 이미지**는 드라이브 폴더에 저장됩니다. 모아보기 카드의 "원본" 링크는 선생님 계정에서만 열립니다.
- **누구나 제출할 수 있는 구조입니다.** 링크는 수업 시간에만 공유하고, 장난 제출은 삭제하세요.
- **학생 얼굴 사진이 저장됩니다.** 학교 개인정보 지침을 확인하고, 활동이 끝나면 드라이브 폴더를 정리하세요.
- **Code.gs를 고쳤다면** 배포 → 배포 관리 → ✏️ 수정 → 버전: **새 버전** → 배포를 누릅니다. 이렇게 하면 주소가 바뀌지 않습니다.
- **index.html을 고쳤다면** GitHub 저장소에서 파일을 다시 올리면 됩니다. 1~2분 뒤 반영됩니다.
